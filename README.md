Para rodar os códigos de teste, no caso, `exemploSimples.py` e `utilizacaoReuso.py`, basta executar `python3 <nomeDoArquivo>`. Além disso, se aconselha a utilização de sistemas operacionais baseados em UNIX, como Linux e MacOs. Caso o usuário se encontre no Windows, aconselha-se a utilização do WSL (Windows Subsystem for Linux) para a execução da biblioteca.
